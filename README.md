# BOZ213u02a04-2.2.6-25040109
Python Literalleri ve Stringler

## Proje Hakkında

Bu proje, BOZ213 Nesne Tabanlı Programlama dersi kapsamında verilen 2.2.6 LAB Python Literalleri ve Stringler ödevi için hazırlanmıştır.

Uygulamada Python programlama dilinin `print()` fonksiyonu kullanılarak metinlerin çift tırnak işaretleri içerisinde ve alt alta yazdırılması amaçlanmıştır.

## Projenin Amacı

- Python'da `print()` fonksiyonunun kullanımını öğrenmek.
- String (metin) literallerini tanımak.
- `\n` kaçış karakteriyle alt satıra geçmek.
- `\"` kaçış karakteriyle çıktıda çift tırnak işareti göstermek.
- Tek satırlık kodla birden fazla satırdan oluşan çıktı elde etmek.

## Python Kodu

```python
print("\"I'm\"\n\"Learning\"\n\"Python\"")
```

## Beklenen Çıktı

```text
"I'm"
"Learning"
"Python"
```

## Kodun Açıklaması

| Kod | Görevi |
|---|---|
| `print()` | Ekrana çıktı yazdırır. |
| `\"` | Çift tırnak işaretini çıktıda gösterir. |
| `\n` | Yeni satıra geçilmesini sağlar. |
| `" "` | Python'da metin ifadesini belirtir. |

## Kullanılan Teknolojiler

- Python 3
- Python IDLE

## Programın Çalıştırılması

1. Python IDLE programı açılır.
2. `File > New File` seçeneğiyle yeni dosya oluşturulur.
3. Python kodu yazılır.
4. Dosya `.py` uzantısıyla kaydedilir.
5. F5 tuşuna basılarak program çalıştırılır.
6. Sonuç IDLE Shell ekranında görüntülenir.

## Öğrenilenler

Bu uygulama sayesinde Python'da string literallerinin kullanımı, kaçış karakterleriyle çıktı biçimlendirme ve tek bir `print()` fonksiyonuyla çok satırlı metin oluşturma öğrenilmiştir.
